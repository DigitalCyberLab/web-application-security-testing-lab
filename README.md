# Web Application Security Testing Lab

## Project Overview

This project focuses on web application security testing using OWASP Juice Shop and OWASP ZAP in a controlled lab environment.

The objective is to identify, analyze, and document common web application vulnerabilities, understand their potential security impact, and recommend appropriate remediation measures.

## Project Objectives

- Deploy an intentionally vulnerable web application using OWASP Juice Shop.
- Configure OWASP ZAP for web application security testing.
- Perform automated and manual security assessments.
- Identify common web application vulnerabilities.
- Analyze security findings and their potential impact.
- Document assessment results and remediation recommendations.

## Tools and Technologies

- OWASP Juice Shop
- OWASP ZAP
- Docker
- Ubuntu Linux Server
- VirtualBox
- Nmap
- GitHub

## Lab Environment

The lab uses a dedicated Ubuntu Server virtual machine hosted in Oracle VirtualBox.

OWASP Juice Shop is deployed as a Docker container and accessed locally through an SSH tunnel.

## Web Application Security Assessment

The assessment will focus on identifying and analyzing common web application security weaknesses, including:

- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- Authentication and session management weaknesses
- Broken access control
- Security misconfigurations
- Other vulnerabilities identified during testing

## Vulnerability Analysis

Identified findings will be reviewed to understand:

- Vulnerability descriptions
- Potential security impact
- Severity and risk
- Evidence collected during testing
- Recommended remediation measures

## Repository Structure

Documentation, screenshots, and assessment reports will be organized into separate folders as the project progresses.

## Disclaimer

This project is conducted for educational purposes in a controlled lab environment using an intentionally vulnerable web application.

Security testing is performed only against systems and applications that I own or have explicit authorization to assess.
