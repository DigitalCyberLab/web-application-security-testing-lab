# Project Overview

## Introduction

This project demonstrates practical web application security testing using OWASP Juice Shop and OWASP ZAP.

The lab provides a controlled environment for identifying common web application vulnerabilities, analyzing security risks, and documenting recommended remediation measures.

## Objectives

- Deploy OWASP Juice Shop using Docker.
- Configure OWASP ZAP for web application testing.
- Perform automated and manual security assessments.
- Identify and analyze web application vulnerabilities.
- Evaluate potential security risks.
- Document findings and remediation recommendations.

## Scope

The assessment is limited to the intentionally vulnerable OWASP Juice Shop application deployed within the dedicated VirtualBox lab environment.

## Expected Outcomes

- Successful deployment of the test application.
- Web application security assessment using OWASP ZAP.
- Documentation of verified security findings.
- Analysis of vulnerability severity and potential impact.
- Practical remediation recommendations.

## Tools Used

- OWASP Juice Shop
- OWASP ZAP
- Docker
- Ubuntu Linux Server
- VirtualBox
- GitHub
